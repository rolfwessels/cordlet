# Simple voice screen

Simplified practical recorder direction: one audio visualization, understated elapsed time, Pause and Send, quiet discard action. Playback is revealed only while paused. Preserve existing fast text entry.

Shared `../theme/tokens.css` uses the existing Android charcoal/background/panel/mint/text palette and existing muted text/border/ink colors. Proposed cool-blue secondary is reserved for optional review controls; existing pink/red is reserved for errors, not normal recording. This is a sketch token proposal, not yet a production Android theme migration.

Browser inspected at 390×844; pause exposes review and Send enters simulated upload. Audio, playback, timer and acceptance are simulations; no microphone, recording file, transcription or network exists in this mockup. `preview.png` is a browser screenshot, not an Android device capture.
